Method

Re-run it yourself

git clone https://github.com/aoyamari/void && cd void
pip install -r requirements.txt
python -m void dao        # every Sputnik DAO + proposal, plain NEAR RPC, no key
python -m void contracts  # optional: contract survival via BigQuery
python -m void build      # recompute survival + thesis verdicts
python -m http.server -d site
